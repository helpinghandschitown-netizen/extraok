Change order → invoice

One change, one sheet. Match the exact approved revision to the proposed invoice line. Approval, completion, billing eligibility, and payment are separate checks.

Use your browser's Print command to print this worksheet or save a blank PDF. Fill it in on paper or in your own private document tool. This page has no editable fields and does not save or upload worksheet data.

Write “not verified” for an unknown item. Do not infer approval or payment from silence. Use document references—not passwords, card details, or banking credentials.

Project / change reference / current revision
 
Reviewed by / date checked
 
Approved scope / amount / decision-record reference / conditions
 
Work completed / remaining work / evidence reference
 
Agreed billing milestone / evidence that it is met
 
Earlier invoice lines / applicable credits / duplicate-charge check
 
Payment allocation / source and date checked / or not verified
 
Proposed invoice reference / line / amount / verified tax treatment
 
Open question / next action / responsible person / follow-up date
 

Before sending: confirm the revision, resolve conditions, check prior billing, and retain the supporting records. Keep completed sheets private.
